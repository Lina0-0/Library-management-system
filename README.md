# Library-management-system
A simple library management system built with C++ and Qt6, featuring a GUI for managing students and library records.

## Features
- Graphical user interface built with Qt Widgets
- Manage student records
- Library management functionality
- Cross-platform (Windows, macOS, Linux)

## Requirements
- CMake 3.19+
- Qt 6.5 or later (Core and Widgets modules)
- A C++ compiler

## Build
```bash
cmake -B build
cmake --build build
